# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in crib, please report it through [GitHub's private vulnerability reporting](https://github.com/fgrehm/crib/security/advisories/new).

Please include:

- A description of the vulnerability
- Steps to reproduce
- The potential impact

Please do not open a public issue for security vulnerabilities. As the project is no longer actively maintained, a response or fix is not guaranteed.

## Supported Versions

crib is [discontinued](https://fabiorehm.com/blog/2026/10/09/im-done-with-dev-containers/). No versions currently receive security updates.
